# hxwl-11 儿童近视进展随访台

在原「眼科验光记录」基础上扩展的儿童近视进展随访台：按患儿、复查日期与眼别管理球镜、等效球镜与眼轴，自动判定进展风险并驱动随访流程。

## 技术栈

React 19 + Vite 7 + TypeScript（严格模式）+ CSS，数据持久化于浏览器 localStorage。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5111；构建：`npm run build`

## 业务规则

- **唯一记录**：业务唯一键为 `患者 + 日期 + 眼别`，同日同眼只保留一条逻辑记录；重复录入被阻止并弹出冲突提示。
- **修订留痕**：修改不能覆盖旧值，只能在该记录上追加一个**带修改原因**的新版本；版本链按时间保留全部旧值。
- **进展判定**：以同眼最近一次**非草稿**复查为基线（间隔不足 30 天不评价），变化量按 182.625 天折算半年等效速率：
  - 半年眼轴增长 **> 0.20 mm**，或
  - 半年等效球镜下降 **> 0.50 D**
  - 任一越线 → 转**重点随访**，必须填写**户外时长**与**处置计划**；资料未齐只能存**草稿**（也可手动存草稿）。
- **刷新一致**：时间线、风险等级、随访状态均由持久化数据经纯函数重算，修订后自动连带重评后续记录。
- **冲突提示**：弹窗显示患者、日期、眼别与原值（球镜 / 等效球镜 / 眼轴等），可一键转为修订流程。

## 分层结构（数据 / 规则 / 页面分开）

```
src/
├── data/            # 数据层：只关心存储、唯一键、版本追加，不懂医学规则
│   ├── types.ts     # 领域类型（Patient / ExamDoc / ExamVersion …）
│   ├── repository.ts# 纯仓储：addExam(唯一约束) / reviseExam(版本追加) / localStorage
│   └── seed.ts      # 可复现的演示数据
├── rules/           # 规则层：纯函数，无 React / 无存储
│   ├── progression.ts # 阈值、半年速率折算、越线判定
│   ├── status.ts      # 风险等级、随访状态（重点/常规/草稿）判定
│   └── timeline.ts    # 双眼时间线、指标汇总、表单提交前预览
└── pages/           # 页面层：只做交互与展示，规则一律调用 rules
    ├── useClinic.ts     # 状态编排（组合仓储 + 派生）
    ├── MetricsBar.tsx
    ├── PatientSidebar.tsx
    ├── TimelineView.tsx # 时间线 + 版本链
    ├── ExamForm.tsx     # 录入/修订 + 实时规则预览
    └── ConflictDialog.tsx
```

## 演示数据

内置 4 名患儿，覆盖：越线转重点随访（含一次带原因订正形成的版本链）、观察带、越线未补齐资料的草稿、仅有基线、首次建档等场景。页头「重置演示数据」可还原。
